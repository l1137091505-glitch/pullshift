# PULLSHIFT

PULLSHIFT is a two-side native BOT tension arena for BOT Chain. Players lock BOT behind Ember or Tide. Every pull extends a capped round timer; after expiry, the heavier side wins and its members split the full pot pro rata.

- Original sports-broadcast interface, not a comic layout.
- Adminless round settlement and next-round opening.
- Draw refunds, winner claims and per-wallet position tracking.
- Automatic wallet account/network change handling.
- Preview feed when no contract address is configured.

Environment: `VITE_PULLSHIFT_ADDRESS=0x...`
